# Hostel Booking System

A web application built with ASP.NET (C#) for managing hostel room bookings, with separate dashboards for students and administrators.

## Features
- Student registration and login
- Room booking requests
- Admin dashboard to approve/manage bookings
- Room management (add/view/edit rooms)
- View student details

## Tech Stack
- ASP.NET Web Forms (C#)
- HTML, CSS, JavaScript
- SQL Server (via App_Data)

## Known Limitations / Future Improvements
- Date selection for bookings is not yet implemented — currently bookings don't capture a specific date/duration. Planned as a future enhancement.

## How to Run
1. Open `HostelBooking.sln` in Visual Studio
2. Let Visual Studio restore NuGet packages automatically
3. Build and run the project (F5)
